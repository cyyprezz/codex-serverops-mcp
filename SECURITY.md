# Security policy

Do not include real passwords, private keys, passphrases, tokens, customer hostnames or production
output in a public issue. Use GitHub Private Vulnerability Reporting when it is available. If the
private form is not visible, contact Nicklas Desens at `nicklas@desens.dev`. Use a neutral subject
and omit exploit details from an initial unencrypted message so a suitable private channel can be
arranged.

The supported security boundary and known limitations are documented in
[`docs/security.md`](docs/security.md). Version `0.1.1` remains alpha software; release-candidate
working trees and wheels must not be represented as published until the signed release completes.
